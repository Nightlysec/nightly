## Prerequisites

- Docker (running)
- An LLM API key from any [supported provider](/llm-providers/overview) (OpenAI, Anthropic, Google, etc.)

## Installation

<Tabs>
  <Tab title="curl">
    ```bash
    curl -sSL https://strix.ai/install | bash
    ```
  </Tab>
  <Tab title="pipx">
    ```bash
    pipx install nightly-agent
    ```
  </Tab>
</Tabs>

## Configuration

Set your LLM provider:

```bash
export NIGHTLY_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-api-key"
```

<Tip>
For best results, use `openai/gpt-5.4`, `anthropic/claude-opus-4-6`, or `openai/gpt-5.2`.
</Tip>

## Run Your First Scan

```bash
nightly --target ./your-app
```

<Note>
First run pulls the Docker sandbox image automatically. Results are saved to `nightly_runs/<run-name>`.
</Note>

## Target Types

Nightly accepts multiple target types:

```bash
# Local codebase
nightly --target ./app-directory

# GitHub repository
nightly --target https://github.com/org/repo

# Live web application
nightly --target https://your-app.com

# Multiple targets (white-box testing)
nightly -t https://github.com/org/repo -t https://your-app.com

# Targets from a file, one target per non-empty, non-comment line
nightly --target-list ./targets.txt
```
